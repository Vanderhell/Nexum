# Project reports

This directory contains point-in-time engineering reports. They document the
state of the implementation when each review was performed; current public API
and behavioral requirements remain defined by the authoritative specification,
headers, and tests.

- [Architecture freeze report](ARCHITECTURE_FREEZE_REPORT.md) records the v0.1
  architecture freeze and its evidence.
- [Implementation hardening report](IMPLEMENTATION_HARDENING_REPORT.md) records
  the implementation-hardening review and validation results.
